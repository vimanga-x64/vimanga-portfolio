# Interactive keyboard attribution

The keyboard scene and press/release sound files in this directory are adapted
from Naresh Khatri's open-source 3D portfolio template:

- Source: https://github.com/Naresh-Khatri/3d-portfolio
- Source revision inspected: `1fb3691f767d8c9602f7a79d48621f9687e44ad1`
- Original files: `public/assets/skills-keyboard.spline` (served here with the
  runtime-oriented `.splinecode` extension) and
  `public/assets/keycap-sounds/`
- The source README describes the project as available under the MIT License
  and requests a credit/link to the original repository.

The surrounding HTML, CSS, JavaScript integration, portfolio descriptions, and
responsive presentation were adapted for Vimanga Umange's portfolio.

The locally vendored Spline web runtime is `@splinetool/runtime` version
`1.12.0`, pinned from https://www.npmjs.com/package/@splinetool/runtime so the
keyboard does not depend on a third-party CDN request at runtime.
